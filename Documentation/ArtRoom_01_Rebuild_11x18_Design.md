# ArtRoom_01 11x18 重做设计规格

日期：2026-10-01  
状态：Stage 2A 设计锁定，尚未重新 Publish 到 Production_Main。

## 1. 重做目标

旧 ArtRoom_01 为 13x21，家具与阻挡密度过高，实际观感容易缩成“玩具屋／模型屋”，并且旧版墙体、可走区和局部碰撞之间存在大量补丁关系。

新版固定为 11x18，并从空白骨架重新设计。目标不是缩放旧图，而是改变空间语言：

- 房间应首先像一个真实使用过的画室，其次才像游戏房间。
- 用少量大体量物件建立尺度，不用大量细碎家具填满画布。
- 中央保留明显的大块负空间，避免迷宫式摆件。
- 视觉重点放在“高墙、巨幅未完成画、长期积累的颜料痕迹、静止光线”。
- 扭曲感来自尺度、光线和不合理的空间安静感，不依赖恐怖物件堆砌。
- 保持足够开阔的战斗空间，允许以后配置低频但大范围弹幕型敌人。

## 2. 固定技术规格

- TemplateId：Production_ArtRoom_01
- Fidelity：HighPrecision
- RoomTag：Standard
- Size：11 x 18 cells
- Cell：1 Unity Unit
- PPU：64
- Runtime Canvas：704 x 1152 px
- Rotation：禁止 90 度旋转
- 每层最多 1
- Socket：South_0
- Door Width：2 cells
- 当前门格：x=4,5 / y=0
- Stage 2 期间继续保持未发布状态

统一 Sorting Order：

- Floor：-10
- Objects：0
- Player / Enemy：20
- Effects：25
- Foreground：30

Effects 必须可以覆盖 Player / Enemy，用于窗光、颜料反光、尘埃与薄雾等简易光影；Foreground 仍然高于 Effects。

## 3. 构图原则

房间纵向较长，玩家从南侧偏左中央进入。

### 南部：入口与缓冲区（y=0~4）

保持明显空旷。

- 南门外延路径必须直接连到中央。
- 左下只允许少量墙边杂物，不形成视觉堵塞。
- 右下可放一块靠墙的大空画布或布帘，但不得把入口压成狭窄走廊。
- 玩家进入后应在 1~2 秒内读懂房间主轴，不应首先撞上家具。

### 中部：工作核心（y=5~12）

这是主要游戏空间，也是画室“正在被使用”的证据。

- 中央偏右放一组主画架 / 大画布，整体约 2~3 格宽、3~4 格高的视觉体量。
- 画架不要正对镜头完全平行，轻微偏转，避免棋盘摆件感。
- 画架附近可有一个矮凳、颜料箱或调色台，但最多形成一个局部群组。
- 中央偏左必须保留一条宽通道。
- 核心战斗空区目标约为 5x7 格以上，不被硬碰撞切碎。

### 北部：尺度锚点（y=13~17）

北墙承担“空间很高、很深”的错觉。

- 北墙放一幅明显大于普通家具尺度的巨幅未完成画，或多张叠靠的大画布。
- 左北侧设置长工作台 / 水槽 / 清洗区，贴墙处理。
- 右北侧设置高画架储藏架、卷起画布、木框等垂直元素。
- 这里可以较密，但所有密度都贴墙，不能把中央战斗区封死。

## 4. 视觉主题

关键词：

“长期无人打扫但仍在使用的旧画室、阴天自然光、灰绿墙面、旧木、亚麻画布、干涸油彩、粉尘、冷色空气、少量暖赭石颜料”

避免：

- 过多彩色玩具式小物件
- 等距摆放的桌椅
- 每格一个物体的棋盘感
- 过度可爱化的艺术用品
- 纯恐怖血污
- 把整个房间做成仓库
- 强对称
- 所有边缘都塞满细节

建议主色：

- 灰绿 / 冷灰墙面
- 旧木褐色
- 亚麻米灰
- 暗蓝灰阴影
- 少量赭石、深红、群青作为旧颜料残留

## 5. 四层拆分

### Floor

只放不会遮挡角色的永久平面信息：

- 地板
- 固定墙面
- 南门框 / 永久建筑结构
- 大面积旧颜料污渍
- 地板磨损
- 胶带定位痕迹
- 被清洗过留下的浅色水痕

Floor 不承担明显高于地面的家具。

### Objects

绝大多数实体物件：

- 主画架与画布
- 工作台 / 水槽
- 储藏架
- 叠靠画框
- 矮凳
- 颜料箱
- 卷画
- 石膏像或静物模型（仅 1 组，不能散落成玩具阵列）

本层后续是主要碰撞依据。

### Foreground

按需存在，控制在很少的面积：

- 靠近镜头一侧的大画布边缘
- 垂下的布帘
- 极少量会自然遮住人物的近景物体

Foreground 不能变成第二层 Objects，也不能长期遮住战斗区。

### Effects

必须利用新的 Effects > Actor 规则：

- 从北侧或东北方向切入的柔和窗光
- 局部空气粉尘
- 薄的颜料反光 / 湿痕
- 极轻的冷色雾感

Effects 应覆盖人物但保持低透明度。玩家穿过光带时产生“进入光里”的感觉，而不是角色被白色贴图糊住。

## 6. 预留碰撞逻辑

Stage 2A 不直接写最终 blockedCells，先锁定以下原则：

- 门格 (4,0)、(5,0) 永远可走。
- 从南门到中央、再到北半部至少保留一条连续 2 格宽主通路。
- 硬碰撞尽量来自“贴墙大物件”和主画架，不用碎片式 1x1 阻挡铺满房间。
- 局部 PolygonCollider 只用于真正需要贴合轮廓的少数物件。
- 新版目标是明显少于旧版 96 个 blockedCells。
- 不继承旧版 34 个 HardBlock + 3 个局部 PolygonCollider 结构。
- 最终碰撞必须在新母图完成后重新审图生成。

## 7. 游戏空间要求

为了后续高方差敌人设计，画室不能只是一间观赏房。

预留：

- 中央大范围移动空间
- 至少一条可绕主画架的侧向路线
- 不允许形成只有单格宽的强制走廊
- 玩家被围攻时应能通过一次击退 + 卖血穿出局部包围
- 如果未来画室敌人采用“低攻击频率、大量弹幕”的方案，房间本身必须提供足够躲避面积

## 8. Stage 2 交付顺序

1. 先制作 11x18 Master 母图，确认整体空间与尺度。
2. 母图通过后再拆 Floor / Objects / Foreground / Effects。

4. 再根据最终 Objects 审图生成 blockedCells 与局部碰撞。

6. 完成运行时验收后删除 Stage 1 一次性重建工具。
