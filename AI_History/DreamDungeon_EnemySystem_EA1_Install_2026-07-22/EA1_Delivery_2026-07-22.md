# 2D环形梦境：敌人系统 EA1 交付说明

## 本阶段完成内容

- 建立五个稳定 `EnemyId` 与五份 `EnemyDefinition`。
- 建立 `EnemyCatalog` 的唯一性、空引用与查找接口。
- 将当前敌人的生命、移动、感知、接触伤害、碰撞、视觉与 CA1 动画来源迁移到 `Enemy_Wanderer`。
- 保留旧字段作为隐藏回退；Definition 丢失时不会让场景直接无法生成敌人。
- 建立房间混合遭遇配置结构：完整方案权重、固定成员、加权随机成员与低/中/高密度。
- 建立外部 `RoomEncounterCatalog`，允许同一视觉房间模板对应不同房间定义；EA1 不绑定实际房间。
- 建立伤害归因与当前 Run 的敌人记录，区分玩家击杀、其他死亡、存活离层与异常消失。
- 保留 `Health.Died` 旧接口、R8.3 安全出生格、一次性提交与 CA1 动画契约。
- 增加 EA1 编辑器审计与调试覆盖层统计。

## 当前明确不做

- 不启用另外四种敌人的实际生成或专属 AI。
- 不执行房间 Encounter Profile。
- 不重写 A*、巡逻、搜索、返回与主动攻击状态。
- 不实装玩家普通攻击、第二攻击槽、投射物或攻击许可。
- 不实现结局判断与存档；只提供未来所需记录接口。

## 静态验证结果

- 新增与修改的 14 份 C# 源文件均通过 C# 语法树解析。
- Unity 资源 Meta GUID 重复数：0。
- 缺失 Meta 文件数：0。
- GameScene 的 Catalog 与默认 Definition 引用已解析到有效资产。
- `Enemy_Wanderer` 与旧 GameScene 的 17 项运行参数、Sprite 与 CA1 Profile 逐项一致。
- 相对上传基线，改动范围仅限预定的 6 个原文件以及新增 EA1 文件。

本环境没有 Unity Editor，因此最终编译、Play Mode 与换层回归必须在 Unity 6000.0.26f1 中完成。项目内 `EA1_README.txt` 给出了完整验收顺序。
